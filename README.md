📚 Teste de Software — 2º Bimestre

Repositório destinado ao desenvolvimento e à organização das atividades práticas da disciplina de Teste de Software, referentes ao segundo bimestre.

O projeto reúne exercícios e práticas desenvolvidos ao longo da disciplina, com foco no aprendizado de conceitos de qualidade de software, testes e integração de aplicações.

Diretório que contém os exercícios complementares relacionados aos conteúdos estudados.

☕ Atividade 03 — Integração com Spring Boot

Diretório destinado aos exercícios de integração utilizando o framework Spring Boot, permitindo trabalhar conceitos de desenvolvimento e integração de aplicações.

🎯 Objetivos
Aplicar na prática os conceitos estudados na disciplina de Teste de Software.
Desenvolver atividades relacionadas à qualidade e confiabilidade de sistemas.
Compreender práticas de testes e integração de software.
Desenvolver habilidades técnicas por meio de exercícios práticos.
Organizar e documentar as atividades desenvolvidas durante o bimestre.
